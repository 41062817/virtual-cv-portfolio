# Virtual CV Portfolio Website

## Overview

This repository contains my personal Virtual CV and portfolio website. The website was developed to showcase my academic background, technical skills, projects, achievements, and professional information as a final-year Information Technology student.

The portfolio serves as an online version of my CV and provides links to my professional profiles and GitHub projects.

## Features

- Personal introduction and professional profile
- About Me section
- Technical skills section
- Education background
- Academic and personal projects
- Achievements section
- Downloadable CV
- Contact information
- Links to GitHub projects and LinkedIn profile
- Responsive design for different screen sizes
- Interactive navigation using JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

Running the Project Locally

To run the portfolio website locally:

Clone the repository:
git clone https://github.com/41062817/virtual-cv-portfolio.git
Open the project folder.
Open index.html in a web browser.

No additional software or dependencies are required to run the website.

Deployment:

The website is deployed using GitHub Pages and can be accessed through the public portfolio URL.
